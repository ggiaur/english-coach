# TASK_LANGUAGE.md — simple task language for the early weeks

Why: on 2026-11-07 (John 9, voice) BJ could not follow compound questions, long sentences
and examples given together with the task. Until the task words below are secure, the tutor
uses only this language for instructions.

## 1. The task words (the whole instruction vocabulary)

| Word | Means | Example |
|------|-------|---------|
| Listen. | Do not speak. Only listen. | `Listen.` |
| Repeat. | Say the same words after me. | `Repeat. He saw a man.` |
| Again. | Do it once more. | `Again.` |
| Slower. | I speak more slowly. (BJ may say it too.) | `Slower, please.` |
| Yes or no? | Answer with one word. | `Is Tom in sales? Yes or no?` |
| A or B? | Choose one. | `Sales or IT?` |
| One word. | Answer with one word. | `Who calls the help desk? One word.` |
| A sentence. | Answer with a full short sentence. | `What does Tom forget? A sentence.` |

Rule: the tutor teaches these 8 in the first 5 minutes of the first lesson, one by one,
with a demonstration (the tutor does the task, then BJ does it). Do not explain them in Hungarian.

## 2. Turn rules

1. One instruction per turn.
2. One question per turn. No "X, and also Y?"
3. Task sentences: at most 5 or 6 words. Teaching sentences in lessons L1 to L3: at most 6 words.
4. The task comes last in the turn, then stop. Do not add an example after it.
5. Never give the answer, or a hint that is the answer, with the question.
6. One correction per turn. Feedback is 1 to 3 words, then the next task.
7. Use the same words for the same task every time (`Repeat.`, not "say it", "try it", "pronounce").
8. Questions: no long wh-questions in the first weeks. Use the question ladder:
   yes or no, then A or B, then one word, then a sentence.

## 3. Task rescue (Claude's proposal, not yet approved by the owner)

If BJ does not answer, or answers a different task:
1. Make the English simpler. Fewer words. Same task. (`Sales or IT?`)
2. Still no answer: say the task as a demonstration (`Listen. Tom works in sales. Repeat.`)
3. After two failed tries on one task: one short Hungarian line that names only the task
   (for example `Ismételd.`), then go back to English at once. Do not explain grammar.
4. Record the item as `task_confusion` in the SESSION RECORD, so the next lesson starts easier.

BJ decides whether this rule stays. Until then, step 3 is used only if BJ asks for it.

## 4. Check

Start of L1 (after the 8 words): ask `Repeat.`, `A or B?`, `Yes or no?`, `One word.`
once each. All four answered with no Hungarian = task language secure. If not, repeat the
mini lesson at the start of L2.
