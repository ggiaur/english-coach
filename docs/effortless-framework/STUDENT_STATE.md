# STUDENT_STATE.md

## Learner goal

Build practical spoken English for:
- everyday communication,
- travel,
- helping foreigners,
- IT support and IT management,
- employment and professional advancement.

## Current provisional level

Active spontaneous speaking appears approximately **A1+ / early A2**.

This is provisional, not a formal CEFR certification.

## Observed strengths

- Understands many simple direct questions.
- Can give short meaningful answers.
- Already has useful English fragments from IT work.
- Can repeat and stabilize a corrected chunk after focused practice.
- Responds well to rapid, short question-answer exchanges once the input is familiar.

## Observed limitations

Common current issues include:
- missing `be`: `I from Hungary` → `I'm from Hungary`
- article use: `I'm IT manager` → `I'm an IT manager`
- third-person `-s`: `John ask` → `John asks`
- building `how to` patterns: `don't know use Excel` → `don't know how to use Excel`
- sentence assembly slows down when vocabulary is not already familiar
- unfamiliar words can block comprehension quickly
- long or fast input becomes difficult before the brain has settled into English mode

## Important learning preferences

- English-only during lesson mode.
- Explanations of unknown vocabulary must also be in English.
- New words/chunks must never simply be assumed known.
- Vocabulary needs multi-angle explanation: meaning, examples, contrasts, non-examples, simple questions.
- Vocabulary explanation should itself be repeated in four speed passes.
- Mini-stories must run four times automatically:
  1. very slow,
  2. very slow,
  3. medium,
  4. natural.
- The first two rounds need genuinely long pauses between sentences.
- No questions between the four story rounds.
- Even after the four rounds, more input must come before testing:
  paraphrase, contrast, alternate wording, teacher-answered questions.
- Only then should active questions begin.
- Questions should progress from yes/no → either/or → who/what → freer answers.
- Short English feedback is useful: `Correct.`, `Better.`, `Try again.`
- English comments are acceptable if they do not interrupt flow.
- Avoid idle pauses and repeated meta-commentary.
- Avoid repetitive praise such as saying `Nice` again and again.
- Do not ask permission to execute phases that are already part of the agreed protocol.

## Current lesson domain

Start with practical IT help-desk situations because the topic is familiar enough to support early spoken English.

Do not stay only in IT long-term. Rotate later into everyday situations as well.
