# QUALITY_CHECKLIST.md

Use before and during every lesson.

## Before the lesson

- [ ] Is the situation practical and concrete?
- [ ] Are there only a few new chunks?
- [ ] Have all important new words/chunks been identified?
- [ ] Are explanations prepared in simple English?
- [ ] Does each new item have examples and contrasts?
- [ ] Is the vocabulary four-speed cycle prepared?
- [ ] Is the full story four-round sequence prepared?
- [ ] Are paraphrases and contrasts prepared before active questions?
- [ ] Is Hungarian unnecessary inside the lesson?
- [ ] Are active questions based only on language already established?

## During vocabulary

- [ ] English only.
- [ ] Do not assume understanding.
- [ ] Four passes: slow, slow, medium, natural.
- [ ] Use meaning + example + contrast + non-example.
- [ ] Teacher may ask and answer questions.
- [ ] Do not force learner production too early.

## During story input

- [ ] Round 1: very slow, long pauses.
- [ ] Round 2: very slow, long pauses.
- [ ] Round 3: medium.
- [ ] Round 4: natural.
- [ ] No interruption between rounds.
- [ ] No permission requests.
- [ ] No comprehension questions yet.

## After story input

- [ ] Paraphrase same facts.
- [ ] Use negatives/contrasts.
- [ ] Use teacher-answered questions.
- [ ] Use alternate viewpoint.
- [ ] Only then begin active learner questions.

## During active practice

- [ ] Start easy.
- [ ] Feedback is short and in English.
- [ ] Never call a wrong answer perfect.
- [ ] If the learner struggles repeatedly, return to input.
- [ ] Isolate difficult pronunciation chunks.
- [ ] Keep momentum; avoid idle pauses.

## End

- [ ] Recycle useful chunks.
- [ ] Record progress in `STUDENT_STATE.md`.
- [ ] If the method itself failed, update `SYSTEM.md`.
