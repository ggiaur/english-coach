# A. Vocabulary / Chunk Preparation

For **each** new item:

## Item: `<word or chunk>`

### Exploration content
Prepare:
- very simple meaning,
- concrete example,
- second example,
- paraphrase,
- non-example / what it does not mean,
- contrast if useful,
- teacher-answered yes/no question,
- teacher-answered either/or question,
- connection to the story.

### Four-speed delivery
- Pass 1 — very slow, long pauses
- Pass 2 — very slow, long pauses
- Pass 3 — medium
- Pass 4 — natural

Do not test the learner yet.

# B. Core Mini-Story

Keep it short and concrete.

## Story text

`[story]`

## Automatic four listening rounds

1. Very slow + long sentence pauses
2. Very slow + long sentence pauses
3. Medium
4. Natural

No interruptions. No questions. No permission requests.

# C. Story Expansion — Still Input First

## C1. Paraphrase
Retell the same facts using simple alternative wording.

## C2. Contrasts / negatives
Explain what is and is not true.

## C3. Teacher-answered questions
Ask and immediately answer the questions yourself.

## C4. Alternate viewpoint
Retell from another character’s viewpoint.

If materially new language appears, explain it using the vocabulary protocol before relying on it.
