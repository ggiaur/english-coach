# LESSON_001 — IT Help Desk: Excel File Will Not Open

Status: prototype lesson  
Goal: establish a small set of useful IT-support chunks through heavy input before output.

## Target chunks

1. `a user`
2. `an Excel file`
3. `cannot open`
4. `error message`
5. `What error message do you see?`
6. `Please restart Excel.`
7. `I’ll check it.`

---

# A. Vocabulary / Chunk Preparation

## 1. `user`

### Content
- `A user is a person.`
- `A user uses a computer, a phone, or a program.`
- `If Maria uses Excel, Maria is an Excel user.`
- `The user is not the computer.`
- `The user is the person using the computer.`
- `Does a user use the computer? Yes.`
- `Is the user a person or a machine? A person.`
- `John works in IT. John helps users.`

### Delivery
Run the complete explanation:
1. very slowly,
2. very slowly again,
3. medium pace,
4. natural pace.

---

## 2. `open a file`

### Content
- `You have a file.`
- `You click the file.`
- `The file appears on the screen.`
- `Now the file is open.`
- `Open does not mean delete.`
- `Open does not mean close.`
- `If you can see the Excel file and work in it, the file is open.`
- `Can you work in the file when it is open? Yes.`

Run four speeds.

---

## 3. `cannot open`

### Content
- `Cannot means you are not able to do something.`
- `The user tries to open the file.`
- `The file does not open.`
- `So the user cannot open the file.`
- `Cannot open is the opposite of can open.`
- `Can the user open the file? No. The user cannot open it.`

Run four speeds.

---

## 4. `error message`

### Content
- `An error message is information on the screen.`
- `It tells you that something went wrong.`
- `For example, Excel may show a message because it cannot open a file.`
- `An error message is not the Excel file.`
- `It is a message about a problem.`
- `Do you see an error message?`
- `If yes, you can tell the IT person what the message says.`

Run four speeds.

---

## 5. `restart`

### Content
- `Restart means stop and start again.`
- `You close Excel.`
- `Then you open Excel again.`
- `That is restarting Excel.`
- `Restart does not mean delete Excel.`
- `Restart does not mean install Excel.`
- `Do you delete the program when you restart it? No.`
- `Do you start it again? Yes.`

Run four speeds.

---

# B. Core Mini-Story

## Story

`John is an IT manager.`  
`He helps users with computer problems.`  
`One user calls John.`  
`The user has a problem with Excel.`  
`The user cannot open an Excel file.`  
`John asks, "What error message do you see?"`  
`The user says, "I don't see an error message."`  
`John says, "Please restart Excel."`  
`John says, "I'll check it."`

## Required delivery

### Round 1
Very slow. Long pause after every sentence.

### Round 2
Very slow again. Long pause after every sentence.

### Round 3
Medium pace.

### Round 4
Natural conversational pace.

Do not interrupt the four rounds.

# D. Active Comprehension

Only start after all previous input is complete.

- `Is John an IT manager?`
- `Is John a doctor?`
- `Does a user call John?`
- `Can the user open the Excel file?`
- `Does the user see an error message?`

### Either / Or
- `Is the problem with Word or Excel?`
- `Is John the user or the IT manager?`
- `Does John say "restart Excel" or "delete Excel"?`

### Who / What
- `Who calls John?`
- `What is the problem?`
- `What does John ask?`
- `What does John tell the user to do?`

# G. Supported roleplay

Tutor:
`Hi. I can't open an Excel file.`

Learner may use:
- `What error message do you see?`
- `Please restart Excel.`
- `I'll check it.`

Keep support visible until the learner can use the chunks comfortably.

---

# H. Lesson success criteria

The lesson is successful when the learner can:
- understand the story at natural pace,
- understand the target chunks without Hungarian translation,
- answer basic comprehension questions,
- pronounce the core chunks intelligibly,
- use at least two support phrases in a short IT roleplay.
